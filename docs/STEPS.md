مشخصات کامل محصول و فرمول‌های آن در **`docs/BANK_SPEC.md`** است و هر استپ به همان سند

## ۰) راهنمای ادامه برای هر هوش مصنوعی بعدی (الزامی — اول کامل بخوان)

کاربر برای ادامه فقط یک جمله می‌گوید: **«استپ بعد را انجام بده»**. این سند به‌تنهایی
کافی است و هیچ وابستگی به گفت‌وگوهای قبلی وجود ندارد:

1. `git pull origin main` بزن، سپس `docs/HANDOFF.md` و همین فایل را کامل بخوان.
2. **اولین استپی که تیک `[ ]` دارد، استپ بعدی است.** شرح کامل همان استپ در همین فایل
   آمده و جزئیات محصولی/فرمول‌ها در `docs/BANK_SPEC.md`.
3. قوانین کار (`docs/AGENT_PROMPT.md` و `.cursor/rules/`): فقط Next.js؛ داده در JSON
   (`data/db.json` + `lib/db.ts`)؛ توکن/رمز/`.env` در گیت ممنوع؛ force-push و تغییر
   git config ممنوع؛ commit کردن `.next`/`node_modules`/`.vercel` ممنوع؛ کتابخانه
   جدید اضافه نکن مگر واقعاً لازم باشد (تقویم شمسی با `Intl` بومی، بدون کتابخانه).
4. استپ را کامل و یک‌جا انجام بده. **معیار اتمام هر استپ** (بدون استثنا):
   `npm run lint` و `npm run build` بدون خطا + تست محلی شرح‌داده‌شده در استپ +
   آپدیت `docs/HANDOFF.md` + تیک‌زدن استپ و آپدیت خط «باقی‌مانده» در همین فایل +
   commit با پیام حاوی شماره استپ (مثل `bank step 5: deposits API`) + push به `origin/main`.
5. اگر در میانه استپ احتمال قطع شدن دادی، همان لحظه در `docs/HANDOFF.md` بخش
   «وضعیت اضطراری» بنویس: کجا ماندی، فایل‌های تغییرکرده، قدم بعدی دقیق. اگر فایل‌ها
   سالم‌اند همان لحظه commit/push کن تا کار گم نشود.
6. در پایان هر استپ به کاربر گزارش بده: کدام استپ انجام شد و چند استپ مانده.

**باقی‌مانده: ۲ استپ از ۲۰** — آخرین آپدیت: 2026-11-24
